# Групповой проект по НИС "Архитектура Big Data систем"

В этом проекте мы построим пайплайн обработки данных о такси с аналитикой и визуализацией.

## Задание

1. Найти любые открытые данные размером более 0.5 ГБ
2. Выбрать любой движок обработки (любая база данных: MySQL/PostgreSQL, будет плюсом Hadoop + Hive)
3. Выбрать любой инструмент интеллектуального анализа данных (R/Python). Будет плюсом построение модели ML или использование GPT
4. Выбрать любой инструмент визуализации (Tableua/Qlik/Power BI/Superset)
5. Распределиться по ролям
6. Проверить минимум 3 гипотезы на основе данных
7. Использовать внешние (дополнительные) источники данных для обогащения/подтверждения гипотез
8. Сделать презентацию на 5 минут, быть готовыми отвечать на вопросы
